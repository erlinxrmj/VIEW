# VIEW

Moderne IPTV-App für Android TV – entwickelt von **Erlin Ramaj**.

- Anmeldung mit **Xtream Codes** (Server-URL, Benutzername, Passwort)
- Links die Länder- und Kategorienliste, rechts die Senderlogos als Kacheln
- **Favoriten**: OK auf einem Sender lange gedrückt halten (oder Menü-Taste) – Favoriten stehen immer zuoberst und werden beim Start zuerst gezeigt
- Vollbild-Player mit Senderwechsel über ▲ / ▼ bzw. CH+ / CH−
- Zurück-Taste in der Senderliste öffnet das Menü (Aktualisieren, Abmelden, Beenden)

## Installieren

Direkter Download für den Fernseher:
https://github.com/erlinxrmj/VIEW/releases/latest/download/VIEW.apk

Die App ist nur ein Player. Inhalte kommen vom eigenen IPTV-Anbieter.
